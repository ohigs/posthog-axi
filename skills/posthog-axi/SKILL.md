## Safety and output

Authenticate only with POSTHOG_PERSONAL_API_KEY.
Never put credentials in argv or files.
Use --host or POSTHOG_HOST and --project or POSTHOG_PROJECT_ID.
The default host is https://us.posthog.com.
Lists default to 25 items.
--limit accepts 1 through 100.
Counts distinguish returned items from total, which can be null.
TOON is the default output.
--json emits JSON.
--fields selects safe fields.
--full disables content previews, never redaction or row limits.
Query --sql and --file are exclusive.
SQL is not rewritten.
Use a SQL LIMIT and time range to bound computation.
No bulk export or query OFFSET pagination is supported.
Pending queries include a scoped query status command.
Failed queries exit 1.
Usage errors exit 2.
Errors are structured on stdout.
Pagination hints preserve host, project, fields, and output flags.
Do not follow raw API next URLs.
Known secret keys and the configured credential are redacted.
Arbitrary secrets in analytics business data cannot be detected.
Hook installation is deferred because SDK 0.1.13 does not safely quote executable paths in shell hooks.
Use the generated Agent Skill instead.
Complete queries report received response rows and returned display rows, not totals.
Complete describes finished execution, not exhaustive results.
backend_has_more is the upstream hasMore boolean or null when absent or null.
truncated is true if display rows were capped or backend_has_more is true.
False truncated with null backend_has_more does not prove backend completeness.
These fields apply to synchronous and completed asynchronous results.
--full never removes row limits.
Narrow SQL and the time range when the backend reports more rows.

- projects accepts `id`, `name`, `timezone`, `created_at`.
- insights accepts `id`, `name`, `derived_name`, `description`, `short_id`, `last_refresh`, `filters`, `query`.
- dashboards accepts `id`, `name`, `description`, `pinned`, `tags`, `tiles`.
- flags accepts `id`, `key`, `name`, `active`, `filters`.
- events accepts `id`, `event`, `timestamp`, `distinct_id`, `properties`.
